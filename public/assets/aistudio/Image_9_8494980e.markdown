## Brand & Style

The design system establishes a high-performance, developer-first environment tailored for intense data structures, algorithms practice, and spaced repetition tracking. The target audience comprises competitive programmers, software engineers preparing for high-stakes technical evaluations, and computer science students. The interface evokes rigorous focus, command-line precision, cognitive momentum, and quiet mastery.

The visual style synthesizes modern dark minimalism with subtle glassmorphic elements and technical cyber-modernism. It relies on deep obsidian and cold slate canvas tones to reduce eye strain over prolonged problem-solving sessions. Structural clarity is reinforced through ultra-thin hairline borders, translucent paneling, and selective high-voltage neon accents that visually code problem difficulty, spaced repetition urgencies, and streak milestones without visual clutter.

## Colors

The palette uses deep zinc-slate undertones layered with high-contrast functional neon accents:

- **Canvas & Surfaces:**
  - Base Background: `#0B0F17` (Obsidian Void)
  - Surface Tier 1 (Cards, Tab Bar): `#111827` (Deep Zinc) with alpha overlays (`rgba(17, 24, 39, 0.75)`)
  - Surface Tier 2 (Hover states, elevated modals, nested modules): `#1E293B` (Slate Elevation)
  - Hairline Borders: `rgba(255, 255, 255, 0.08)` across resting cards, elevating to `rgba(99, 102, 241, 0.4)` on active focus.

- **Semantic & Difficulty Accents:**
  - Primary / Interactive Focus: `#6366F1` (Electric Indigo) for CTA states, active filters, primary navigational highlights.
  - Easy / Mastered / High Streaks: `#10B981` (Emerald). Applied to solved indicators, optimal time complexities, and unbroken streak metrics.
  - Medium / Revisit Due: `#F59E0B` (Amber Gold). Signals optimal spaced repetition revision windows.
  - Hard / Critical Blind Spots: `#EF4444` (Vivid Crimson). Reserved for high-difficulty challenges, failed recall attempts, and critical revision alerts.

- **Content & Text:**
  - High Emphasis: `#F9FAFB`
  - Medium Emphasis / Secondary Labels: `#94A3B8`
  - Disabled / Structural Muted: `#475569`

## Typography

The type system blends structural geometric sans (`Geist`), utilitarian high-density sans (`Inter`), and monospaced technical precision (`JetBrains Mono`).

- **Display & Headlines (`Geist`):** Delivers clean, razor-sharp section demarcations and analytics headers with minimal geometric distraction.
- **Body & Structural Copy (`Inter`):** Handles multi-line problem descriptions, algorithmic notes, and editorial breakdowns with neutral, balanced optical legibility.
- **Data & Algorithmic Accents (`JetBrains Mono`):** Applied exclusively to runtime metrics (`O(N log N)`), memory allocations (`42.8 MB`), submission timestamps, spaced repetition intervals (`R-03`), and code snippets. Letter-spacing for `code-sm` and `code-md` should maintain a neutral to `+0.02em` track for instant scannability on compact screens.

## Layout & Spacing

The layout is built for high data density, avoiding wasteful empty zones while preserving functional visual air.

- **Mobile Viewport (< 640px):** Employs a single fluid column constrained with `1rem` outer horizontal margins. Compact components utilize `space-sm` (`0.5rem`) and `space-md` (`0.75rem`) internal padding to optimize screen space for dual-metric comparisons (e.g., acceptance rate alongside spaced repetition cadence).
- **Tablet / Large Viewport (>= 640px to 1024px):** Uses an 8-column grid with `1rem` gutters, allowing side-by-side split screens (e.g., problem feed adjacent to the flash-revision queue).
- **Desktop Viewport (> 1024px):** Max container width is anchored at `1200px` within a 12-column structure with `margin-desktop` (`2rem`) outer boundaries and `gutter` (`1rem`) column gaps.
- **Vertical Spacing Rhythm:** Component interiors strictly scale in multiples of `0.25rem` (4px base unit), enforcing consistent structural rhythm between metadata pills, title locks, and action zones.

## Elevation & Depth

Depth is established primarily through translucent layering and delicate luminosity gradients rather than heavy drop shadows:

- **Base Layer (Level 0):** `#0B0F17` pure solid background canvas.
- **Floating Glass Surfaces (Level 1):** Background `rgba(17, 24, 39, 0.75)` with a backdrop blur filter of `16px` and a single-pixel hairline rim: `1px solid rgba(255, 255, 255, 0.08)`.
- **Raised & Active Panels (Level 2):** `#1E293B` at full or 90% opacity. Enhanced with a soft directional glow: `0 8px 24px -4px rgba(0, 0, 0, 0.5), 0 0 0 1px rgba(255, 255, 255, 0.12)`.
- **Accent Glow Highlights (Semantic Overlays):** Interactive highlights and alert states emit subdued, color-tinted ambient glows. For example, active revision alerts employ a `box-shadow: 0 0 16px -2px rgba(245, 158, 11, 0.25)`, creating an illuminated cockpit aesthetic against the deep dark canvas.

## Shapes

The design system standardizes on crisp, controlled geometry with a balanced `roundedness: 2` (base `0.5rem` / 8px).

- **Standard Containers & Cards:** `0.5rem` (`rounded`) corner radius. This keeps technical and tabular data sharp, orderly, and architectural.
- **Interactive Action Buttons & Inputs:** `0.5rem` (`rounded`) to match container alignment.
- **Pills, Badges & Streaks:** Fully circular / pill geometry (`9999px`) for algorithmic tags (e.g., `Dynamic Programming`, `Graphs`), difficulty tags, and spaced repetition countdown counters, ensuring immediate visual differentiation from structural cards.
- **Floating Modals & Sheets:** `1rem` (`rounded-lg`) along active sheet boundaries.

## Components

### Buttons
- **Primary:** Solid `#6366F1` background, `#FFFFFF` text, `font-family: Inter; font-weight: 600; font-size: 14px`. Padding: `0.5rem 1rem`. Micro-border: `1px solid rgba(255, 255, 255, 0.2)`. Active state drops scale by 1.5% with an ambient Indigo glow.
- **Secondary / Ghost:** `rgba(255, 255, 255, 0.04)` fill, `1px solid rgba(255, 255, 255, 0.08)` border, `#F9FAFB` text. Hover transitions border to `rgba(255, 255, 255, 0.2)` and background to `rgba(255, 255, 255, 0.08)`.
- **Destructive / Reset:** Semi-translucent Crimson tint `rgba(239, 68, 68, 0.12)` with `1px solid rgba(239, 68, 68, 0.3)` and `#EF4444` label.

### Chips & Badges
- **Difficulty Badges:** Pill-shaped with `0.25rem 0.625rem` padding.
  - Easy: Background `rgba(16, 185, 129, 0.12)`, text `#10B981`, border `1px solid rgba(16, 185, 129, 0.25)`.
  - Medium: Background `rgba(245, 158, 11, 0.12)`, text `#F59E0B`, border `1px solid rgba(245, 158, 11, 0.25)`.
  - Hard: Background `rgba(239, 68, 68, 0.12)`, text `#EF4444`, border `1px solid rgba(239, 68, 68, 0.25)`.
- **Metadata Chips:** JetBrains Mono font (`code-sm`), subtle zinc background (`#1E293B`), text `#94A3B8`.

### Cards & Problem Items
- Translucent backdrop blur card (`rgba(17, 24, 39, 0.75)`), `0.5rem` radius, `1px solid rgba(255, 255, 255, 0.08)` border.
- Layout: Top bar displays problem index and title in `headline-sm`, right-aligned difficulty badge. Bottom bar nests metadata in `JetBrains Mono` showing Space/Time complexity tags, last revised delta (e.g., `due in 4h`), and confidence score indicator bar.

### Input Fields & Search
- Background: `#111827`, border: `1px solid rgba(255, 255, 255, 0.1)`. Radius `0.5rem`.
- Focus state: Border transitions to `#6366F1` with an outer ring `0 0 0 1px #6366F1`.
- Search fields include monospaced hotkey badges (e.g., `⌘K`) in muted zinc.

### Lists, Checkboxes & Radio Controls
- List rows feature clean border separators (`1px solid rgba(255, 255, 255, 0.04)`), active hover states shift background to `rgba(255, 255, 255, 0.03)`.
- Checkboxes: Square with `0.25rem` radius, dark base, checked state fills with `#10B981` (Mastered) or `#6366F1` (Active Queue) with a clean white vector glyph.

### Mobile Bottom Navigation
- Fixed floating bar with `backdrop-filter: blur(20px)` over `rgba(11, 15, 23, 0.85)`, top border `1px solid rgba(255, 255, 255, 0.08)`.
- Active tab displays an Electric Indigo icon, glowing micro-dot indicator below the label, and text in `#F9FAFB`. Inactive tabs render in `#94A3B8`.

### Streak Counters & Spaced Repetition Heatmaps
- Streak metric utilizes a high-contrast pill containing a flame glyph in `#F59E0B` and count in `JetBrains Mono` bold.
- Revision urgency indicators: Mini progress rings or status pulses indicating the decay status of memory curves based on SM-2 spaced repetition algorithms.
